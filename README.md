# lowrideliferadio.com

Public GitHub Pages site for [Lowride Life Radio](https://lowrideliferadio.com).

This repo holds the live static build at the repository root (`CNAME` + `.nojekyll`).
Pages is served from the `main` branch, folder `/` (root). There are no server secrets in this tree.

The player streams from `https://stream.lowrideliferadio.com` (HTTPS on port 443).
